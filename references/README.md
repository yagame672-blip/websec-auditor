# 📚 websec-auditor Official Reference Library

This directory contains official reference books, standards, CheatSheets, and RFC specifications used to ground all vulnerability findings and remediations in **websec-auditor**.

## 📖 Available Reference Documents & Standards

### 🛡️ IETF RFC Specifications
- **RFC 9116**: A File Format to Aid in Security Vulnerability Disclosure (security.txt)
- **RFC 6797**: HTTP Strict Transport Security (HSTS)
- **RFC 6265**: HTTP State Management Mechanism (Cookie Flags: Secure, HttpOnly, SameSite)

### 🌐 OWASP Security CheatSheets & Manuals
- **Content Security Policy (CSP)**: CSP header directives and XSS mitigation.
- **Clickjacking Defense**: X-Frame-Options and frame-ancestors.
- **Cross-Site Request Forgery (CSRF)**: Anti-CSRF tokens and SameSite cookie defense.
- **Cross-Site Scripting (XSS) Prevention**: Context-aware HTML/JS/CSS output encoding.
- **SQL Injection (SQLi) Prevention**: Parameterized queries and ORM safety.
- **Server-Side Request Forgery (SSRF)**: Private IP blocking and egress validation.
- **Session Management**: Session ID generation, cookie scope, and session invalidation.
- **REST & API Security**: API token authentication, rate limiting, and input validation.
- **GraphQL Security**: Query complexity limits, introspection controls, and authentication.
- **Transport Layer Security (TLS)**: Modern TLS 1.3 configuration, ciphers, and certificate validation.
- **XML External Entity (XXE) Prevention**: Disabling external DTD entity resolution.
- **Third-Party JavaScript & Supply Chain**: Subresource Integrity (SRI) and script sandboxing.
- **Authentication & Password Storage**: Multi-factor authentication and credential hardening.
- **Authorization & Access Control**: Role-based access control and IDOR prevention.
- **Cryptographic Storage**: Strong hashing algorithms (Argon2id, bcrypt) and key management.
- **Input Validation**: Whitelist-based sanitization and type enforcement.
- **HTML5 Security**: postMessage origin validation, sandboxed iframes, and Web Storage security.
- **Vulnerability Disclosure Policies**: Coordinated security disclosure workflows.
- **Unvalidated Redirects and Forwards**: Open redirect validation.
